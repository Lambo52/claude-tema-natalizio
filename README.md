# 🎄 Tema natalizio per Claude Code

Una mod per Claude Code che porta il Natale nella tua sessione:

- **sfondo animato**: una notte di Natale con neve che cade, slitta con le renne, paesino, chiesa, albero illuminato e pupazzo di neve. Ogni chat ha una scena diversa;
- **conto alla rovescia** a Natale nella barra di stato;
- comando **`/natale`** per accendere o spegnere il tema;
- comando **`/natale nuova`** per cambiare la scena della chat corrente.

Lo sfondo animato si vede nell'app desktop di Claude (scheda Code); nel terminale compare il conto alla rovescia.

## Installazione

Al prompt di una sessione di Claude Code:

```
/plugin install tema-natalizio --marketplace Lambo52/claude-tema-natalizio
```

Rispondi `y` per aggiungere il marketplace, poi scegli dove installarlo.

Oppure da una shell:

```bash
claude plugin install tema-natalizio --marketplace Lambo52/claude-tema-natalizio
```

## Uso

| Comando | Cosa fa |
| --- | --- |
| `/natale` | Accende o spegne il tema |
| `/natale nuova` | Genera una nuova scena per questa chat |

Buone feste! 🎅
